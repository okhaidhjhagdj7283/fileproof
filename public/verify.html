Kéo thả hoặc click để chọn file
Cách hoạt động
1. FileProof lưu SHA-256 fingerprint của file gốc khi tạo proof.
2. Bạn upload bản sao — fingerprint được tính ngay trong trình duyệt.
3. Hai fingerprint được so sánh. Khớp = file giống hệt bản gốc.
FileProof không chứng minh sự kiện đã xảy ra — chỉ xác nhận file khớp với bản gốc đã lưu.
